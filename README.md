# PARRY VECTOR // GAUNTLET

A 3-boss twin-stick reflect bullet-hell gauntlet built as a single offline HTML5 Canvas + Web Audio file.

## Features
- **3-Boss Gauntlet:** Rotational Lattice, Laser-Anchor Crossfire, and Synchronized Twin Cores, each with a Phase II escalation at 50% HP.
- **Reflect & Overdrive:** Parry incoming crimson projectiles to vent weapon heat, fire high-damage reflected shots back at the boss, trigger a 3-second Overdrive triple-stream burst, and restore 1 shield pip every 3 parries.
- **Two Modes:** **Standard** (per-boss checkpoints; clears unlock Overclocked) and **Overclocked** (1-life master run). Best scores and clear times per mode save locally.
- **Xbox Wireless Controller Supported:** Left Stick move, Right Stick aim, RT fire, LT/LB reflect parry, A confirm, B back to menu, Start pause, D-Pad menu/mode selection, plus dual-rumble and trigger-impulse haptics.
- **Offline Single File:** Zero external CDN dependencies (`index.html` and `parry-vector-gauntlet.html` are identical standalone builds).

## Controls
- **Mac / PC:** `WASD` or Arrow keys to move, Mouse to aim & hold Left-Click to fire, Right-Click / `Space` / `Shift` to parry, `Esc` / `P` to pause (`Esc` again or `B` for Menu).
- **iPad / iPhone:** Twin-stick touch controls (Left Stick move, Right Stick aim & auto-fire, `PARRY` button to reflect).
- **Xbox Controller:** `LS` move, `RS` aim, `RT` fire, `LT` / `LB` parry, `A` confirm, `B` back to menu, `Start` pause, `D-Pad` select mode / menu options.
